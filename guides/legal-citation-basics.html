Legal Citation Basics

A legal citation is not just decoration. It is a map that helps a reader identify the exact authority you relied on, verify it, and find the same material later.

Visual citation structure

Most legal citations answer the same questions

Who / what is cited? When? Where is it reported? Which page, article, section or sequence?

Which citation path should I choose?

  • If your institution asks for SCC, use verified SCC reporter details.
  • If it asks for AIR, use verified AIR year, court and page.
  • If it accepts SCI neutral citation, use year + INSC + sequence.
  • If it asks for OSCOLA, use OSCOLA-style treatment and verify local instructions.

What every legal citation is trying to do

A good citation answers four questions: what is the source, where can it be found, which part is being relied on, and how confident should the reader be that the reference is complete. CiteJury is designed around those questions rather than only around punctuation.

Basic anatomy

Case name + year + reporter / neutral identifier + page or sequence

The exact order depends on the citation system. The principle is the same: each component identifies the source more precisely.

Source type comes first

Before formatting anything, identify the source type. A judgment, statute, constitutional article, book, journal article and website do not need the same information. This is why CiteJury changes field labels and required markers when you change the source type.

  • Judgment: case title, year, reporter or neutral citation, court and page/sequence.
  • Legislation: Act title, year and section or provision.
  • Constitution: title and article or schedule.
  • Journal/book: author/title information, publication details and page/pinpoint.
  • Website: page title, website/publisher, URL and date/year if available.

Required versus optional fields

Required means the selected citation rule cannot produce a useful citation without that information. Optional means the citation may still be generated, but the information can improve identification or may be required by your institution.

Optional should not be treated as unimportant. For example, a court name may be optional in one style but important for a moot memorial or journal submission.

Common citation mistakes

  • Using a PDF page number instead of the reporter opening page.
  • Mixing neutral citations with reporter citations.
  • Guessing missing volume or court abbreviation.
  • Using a search-result snippet instead of the official source or reporter.
  • Assuming one university's preferred style applies everywhere.

How to use CiteJury safely

  1. Choose the citation style and source type.
  2. Complete every field marked Required.
  3. Generate the citation.
  4. Read Citation Anatomy™ to understand what every part means.
  5. Use the verification checklist before submission.

A reliable citation workflow

Identify the source type first, then choose the required citation system. Transcribe source details from an authoritative record, generate the draft, compare each component with the source, and finally check any institution-specific requirements.

Required and optional information

Different citation rules require different fields. CiteJury now labels fields dynamically as Required or Optional for the selected style and source type. Optional does not mean irrelevant: extra details may still improve identification or be recommended by a particular institution.

Common mistakes

Avoid guessing missing metadata, mixing reporter systems, confusing opening pages with pinpoint pages, and treating generated output as a substitute for source verification.
