# Search Console Final Steps

After the final audit and production freeze:

1. Confirm the live homepage is stable.
2. Confirm sitemap.xml is current.
3. Confirm robots.txt references the sitemap.
4. Submit or resubmit sitemap in Google Search Console.
5. Request indexing for the homepage.
6. Request indexing for important guide pages only if materially changed.
7. Check Bing Webmaster Tools sitemap status.
8. Monitor coverage/indexing after release.

Do not repeatedly request indexing during active EP development.
