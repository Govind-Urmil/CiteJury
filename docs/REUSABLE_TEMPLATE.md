# Reusable Static-Site Template

EP-018 extracts reusable structure from CiteJury for future websites.

## Why this matters
CiteJury is the first website. Future websites should be faster to create by reusing:
- Static architecture
- Documentation memory system
- SEO content structure
- Accessibility patterns
- Responsible ad-slot pattern
- Free-hosting readiness

## What was added
- `/template/README.md`
- `/template/site.config.json`
- `/template/index.template.html`
- `/template/assets/css/template.css`
- `/template/assets/js/template.js`
- `/template/docs/PROJECT_CONTEXT.template.md`

## Rules
- No backend by default.
- No architecture change without approval.
- Future websites should start from this template unless there is a strong reason not to.
