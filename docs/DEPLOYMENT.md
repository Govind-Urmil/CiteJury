# Static Deployment Readiness

CiteJury is designed to run as a static website.

## Supported zero/near-zero hosting options
- GitHub Pages
- Cloudflare Pages
- Netlify
- Vercel static deployment
- AWS S3 + CloudFront later if approved

## Current architecture
- No backend
- No database
- No build tool required
- Browser-first JavaScript
- Static HTML/CSS/JS

## Private repo + public site
A private repository can still deploy to public static hosting platforms using deployment integrations.
