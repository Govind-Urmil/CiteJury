# CiteJury Project Context

## Project
CiteJury

## Vision
Privacy-First Legal Citation Generator.
Built with Indian legal practice in mind while remaining useful internationally.

## Core Constraints
- Free-to-host first.
- Browser-based wherever possible.
- No backend unless future ADR approves it.
- Private repository during development.
- Public website later.
- One EP = One commit = One push.
- EPs are immutable after commit.
- Repository docs are the source of truth.
