# ADR: Ad Monetization Activation

## Status
Proposed only. Not active.

## Context
CiteJury intends to remain free for users and may generate revenue through responsible advertising.

## Decision required
Choose whether to enable ads, and if yes, select the provider and placement boundaries.

## Non-negotiable constraints
- No deceptive ads
- No popups/interstitials
- No ads inside active citation form controls
- No ads that break mobile usability
- No backend unless separately approved
- Privacy-first positioning must remain honest

## Evaluation checklist
- Does the ad provider require cookies?
- Does the ad provider require consent banner?
- Does it affect Core Web Vitals?
- Does it slow the citation generator?
- Does it compromise user trust?
- Does it comply with host policies?
