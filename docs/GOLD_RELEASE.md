# CiteJury Gold Release

## Release
EP-030 completes the planned CiteJury engineering roadmap.

## Product
CiteJury is a privacy-first, browser-based legal citation formatting and learning website.

## Architecture
- Static HTML
- Static CSS
- Browser JavaScript
- No backend
- No database
- No Python runtime
- No Node runtime
- No build step
- No active ads
- No active analytics
- Free/static-hosting first

## Trust
- Citation components are explained.
- Generated output includes verification guidance.
- The product does not claim official authority.
- Formal citations should be checked against original sources and required rules.

## Operations
After launch, development should be limited to:
- Reported bug fixes
- Verified citation-rule corrections
- Useful content improvements
- Hosting/domain work
- Approved monetization or analytics decisions

## Immutable EP rule
Committed EPs remain immutable. Corrections are delivered in new EPs.
