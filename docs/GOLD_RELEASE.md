# CiteJury Gold Release

## Release

EP-040 completes the planned CiteJury post-audit roadmap through Final Production Gold Release.

## Product

CiteJury is a privacy-first, browser-based legal citation formatting and learning website with authority-aware citation rules, validation, explainability, manual browser test coverage, production hardening, and static deployment readiness.

## Architecture

- Static HTML
- Static CSS
- Browser JavaScript
- No backend
- No database
- No Python runtime
- No Node runtime
- No build step
- No active ads
- No active analytics
- Free/static-hosting-first

## Trust

- Citation scope is documented.
- Generated output exposes validation and explainability where supported.
- Unsupported authority families are not falsely marketed as generator-ready.
- The product does not claim official authority.
- Formal citations should be checked against original sources and required rules.

## Operations

After launch, CiteJury should be left in a low-maintenance static mode. Development should be limited to verified citation-rule corrections, useful content improvements, production-domain/hosting work, security/privacy fixes, and explicitly approved monetization or analytics decisions.

## Immutable EP rule

Committed EPs remain immutable. Corrections are delivered in new EPs.
