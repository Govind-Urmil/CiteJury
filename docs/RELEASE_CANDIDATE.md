# Release Candidate Notes

## EP-021 Status
CiteJury is now a static launch candidate.

## What is ready
- Static homepage
- Browser-side citation generator
- Modular citation engine
- Citation explanations
- Copy and download output
- Organic guide pages
- Responsible ad-slot reservations
- Static deployment docs
- QA and launch checklists
- Trust and accuracy page

## Important limitation
CiteJury cannot honestly promise 100% legal accuracy for every real-world citation scenario because citation requirements vary by court, institution, journal, publisher, and style guide.

## Trust position
CiteJury should be clear, useful, transparent, and privacy-first. It should help users generate and understand citations while asking them to verify important citations before formal use.

## Bug workflow
If a bug is reported:
1. Reproduce the issue.
2. Record it as a new EP or patch EP.
3. Fix it in a new commit.
4. Update docs/tests if needed.
5. Push the fix.
