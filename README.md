# CiteJury

Privacy-first legal citation tools built with Indian legal practice in mind.

## Current Release
EP-019: Citation style depth expansion.

## Architecture
Static, browser-first, reusable, free-to-host first, and no backend dependency.

## Citation Styles
The browser-side citation engine now supports Indian Legal, SCC-style, AIR-style, and OSCOLA-like output.

## Workflow
One EP equals one Git commit and one Git push.
