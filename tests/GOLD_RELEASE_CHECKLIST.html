CiteJury Gold Release Checklist

Browser-readable final handoff checklist.

  1. Homepage opens.
  2. Citation generator works.
  3. Validation messages work.
  4. Copy action works.
  5. Download action works.
  6. Trust page opens.
  7. Privacy page opens.
  8. Terms page opens.
  9. Guide pages open.
  10. Mobile navigation works.
  11. No backend is required.
  12. No database is required.
  13. No Python or Node runtime is required.
  14. No active ads are loaded.
  15. No active analytics are loaded.
