# Release Smoke Test

Before public launch:

1. Open `index.html`.
2. Generate a judgment citation.
3. Generate a legislation citation.
4. Generate a Constitution citation.
5. Try invalid year validation.
6. Try website URL validation.
7. Copy generated citation.
8. Download generated citation.
9. Open at least five guide pages.
10. Open `trust.html`.
11. Confirm no backend/server is required.
12. Confirm no active ad script is present.
13. Confirm mobile navigation works.
14. Confirm sitemap exists.
15. Confirm GitHub static-check workflow passes.
