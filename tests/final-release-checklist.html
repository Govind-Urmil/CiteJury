CiteJury Final Release Checklist

This is a browser-readable checklist. It does not require Python, Node, backend, database, or build tooling.

  1. Open ../index.html.
  2. Open ../trust.html.
  3. Open ../privacy.html.
  4. Open ../terms.html.
  5. Open multiple files inside ../guides/.
  6. Generate one citation for each available source type.
  7. Confirm validation errors are understandable.
  8. Confirm copy and download actions work.
  9. Confirm mobile menu works.
  10. Confirm no server is running.
  11. Confirm no Python or Node runtime is needed.
  12. Confirm ads are reserved but inactive.
