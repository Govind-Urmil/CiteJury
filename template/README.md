# Reusable Static Site Template

This template extracts the reusable parts of CiteJury so future static websites can be created faster.

## Use Cases
- Informational websites
- Tool-based static websites
- SEO content websites
- Free-to-host product microsites
- Advertisement-supported static websites

## Architecture
- Static HTML
- Static CSS
- Browser JavaScript only
- No backend
- No database
- No build step required

## How to reuse
1. Copy the `template/` folder.
2. Replace brand values in `site.config.json`.
3. Replace content in `index.template.html`.
4. Keep the `/docs` structure for project continuity.
5. Deploy to any static host.
